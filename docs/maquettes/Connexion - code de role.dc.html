Accès à l'outil

Un code ouvre un profil, pas un compte

L'accès se fait par code de rôle : administration, tutorat, ou poste de travail. Un code ne désigne aucune personne — il n'y a ni identifiant nominatif, ni mot de passe individuel, ni historique rattaché à un agent.

Contrôle d'accès inactif — le site est ouvert à quiconque a l'adresse

La base de données n'est pas branchée : aucun code n'est vérifié et tous les écrans sont accessibles. Créez un store Postgres et un store Blob dans l'onglet Storage du projet, puis rechargez cette page.

Cet état doit être levé avant tout usage du dispositif comme preuve en audit.

Entrer un code de rôle

Code non reconnu. Vérifiez la saisie, ou entrez sans code : la consultation reste ouverte.

Sans code, vous accédez aux modules et aux évaluations. Les dépôts de documents et l'ordonnancement des modules demandent un code de tutorat ou d'administration.
